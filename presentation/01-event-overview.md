# Event Overview

> **Source:** [01-event-overview.png](01-event-overview.png)

## Presentation

Presentation events consist of a **presentation or interview with judges**.

### Competitors Must:

- Demonstrate excellent verbal communication skills.
- Display effective decision-making and problem-solving skills.
- Express self-confidence and poise.
- Work well as a team when applicable.
- Exhibit logic and systematic understanding.
- Conduct a professional business presentation.
- Answer questions effectively (when applicable).

---

## Specific Information

| Detail | Value |
|--------|-------|
| **Event Type** | Individual or Team (3 members maximum) |
| **Equipment Setup Time** | 2 minutes (timer starts when 2 minutes are up) |
| **Prep Time** | N/A |
| **Performance Time** | 7 minutes |
| **Warning Time** | 6 minutes |
| **Q&A** | Yes (3 minutes) |

---

## General Guidelines

- Solutions must run **standalone** with no programming errors.
- Data must be free of viruses/malware.
- The usability and functionality of the program must be demonstrated.
- Visual aids and samples specifically related to the demonstration may be used.
- Competitors must show the judges any of the following that are applicable:
  - README file
  - Source code
  - Documentation of templates/libraries used
  - Documentation of copyrighted material used
- **Competitors must prepare projects. Advisers and others are not permitted to help.**
